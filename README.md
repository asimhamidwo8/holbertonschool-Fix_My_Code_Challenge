# Holberton School - Fix My Code Challenge

## Description

This repository contains solutions and debugging exercises from the Holberton School Fix My Code Challenge.

The goal is to identify and fix bugs in existing implementations across different programming languages.

## Challenges

| File                         | Language   | Description                             |
| ---------------------------- | ---------- | --------------------------------------- |
| `0-fizzbuzz.py`              | Python     | FizzBuzz                                |
| `1-print_square.js`          | JavaScript | Print a square                          |
| `2-sort.rb`                  | Ruby       | Sort arguments                          |
| `3-user.py`                  | Python     | User password validation                |
| `delete_dnodeint_at_index.c` | C          | Delete a node from a doubly linked list |

## Testing

Each challenge should be tested according to its requirements.

For the doubly linked list exercise, the C implementation can be compiled with GCC using the required warning flags.

## Learning Objectives

* Debug existing code.
* Understand program logic and edge cases.
* Practice Python, JavaScript, Ruby, and C.
* Test implementations and verify expected behavior.
